# Serus × MineMaker — Independent Strategic Proposal

A static, deployable one-page website prepared by Gráinne Popen (October 2026).

## Run locally
Open `index.html` in a browser; no installation or build step required. Google Fonts loads online, with system font fallbacks.

## Deploy to GitHub Pages
1. Create a new public or private repository (depending on your GitHub Pages plan).
2. Upload `index.html` at the repository root.
3. Go to Settings → Pages → Build and deployment; select **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save, then open the URL shown by GitHub Pages when publishing completes.

Can also be deployed via Netlify Drop, Vercel static hosting, or any conventional web host.

## Demo disclosure
The interactive navigator uses local, deterministic JavaScript. It does not access a funding database, AI service, client information, or live program eligibility data. Every project scenario and output is illustrative. No form data is transmitted or stored.
